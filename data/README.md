# Dataset

The dataset is stored in `[Neusoft Group A08] Medical Insurance Feature Data 16000 (Revised Edition) - Copy.csv`.

Description:
The dataset utilized in this study originates from the 15th China University Student Service Outsourcing Innovation and Entrepreneurship Competition and has been made publicly accessible through various secondary sources. It was deliberately selected for its real-world nature, providing a realistic and challenging benchmark for evaluating the effectiveness, robustness, and generalizability of healthcare fraud detection models.
- Number of samples: 16000
